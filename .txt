
1. Each create a branch locally on their machine by running:

git checkout -b branch-name

2. Push the branch to the remote repo

git push -u origin branch-name

3. Switch between branches
To switch between branches locally:

git checkout branch-name

4. Collaborate and merge
•	Each teammate works in their branch.
•	Once a feature is ready, open a Pull Request on GitHub from their branch to main.
•	Review and merge PR on GitHub.

•	Then teammates update their local repos with:

git pull origin main
